# Service Desk

Сайт типа Service Desk для курсовой работы на тему **обслуживания IT инфраструктуры**. Создан на Python с использованием Flask.

О проекте

Данный проект представляет собой веб-приложение для обработки заявок (тикетов) в IT-инфраструктуре. Система позволяет пользователям создавать заявки на обслуживание, а администраторам — управлять ими и отслеживать статистику.

Возможности версии 1.0.0

- **Две роли**: пользователь и администратор
- **Создание, редактирование и удаление заявок/тикетов**
- **Просмотр отчетности**
- **Добавление и работа со справочниками**

Технологии

- **Python** — язык программирования
- **Flask** — веб-фреймворк
- **SQLite** — база данных (по умолчанию в Flask)
- **Jinja2** — шаблонизатор
- **HTML/CSS** — фронтенд

Роли пользователей

| Роль | Возможности |
|------|-------------|
| **Пользователь** | Создание заявок, просмотр своих тикетов, редактирование |
| **Администратор** | Управление всеми заявками, работа со справочниками, просмотр отчетности |
